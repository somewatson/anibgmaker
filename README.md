# Animated Background Generator
[https://anibgmaker.somewatson.com](https://anibgmaker.somewatson.com)

A professional-grade tool for creating customizable animated backgrounds for videos and shorts.

## 🚀 Features
- **Diverse Themes**: From geometric shapes and particles to complex environments like Tron, Star Wars, and a dynamic Tropical Beach with layered lapping waves.
- **Customizable**: Real-time control over element count, speed, and colors.
- **Audio Engine**: Procedural music and nature sounds (Rain Noise, Ocean Waves) with themes matching the visuals.
- **POV Movement**: Perspective-based visuals (Warp Speed, Tunnel, Beach Shoreline) for an immersive travel feel.
- **Recording Ready**: A "Hide Menu" feature to capture clean, distraction-free footage.
- **Quick Navigation**: Previous/Next buttons for fast theme and music cycling.

## 🛠️ Technical Implementations
- **2D Mode**: High-performance Canvas 2D implementation for lightweight use.
- **WebGL Mode**: GPU-accelerated implementation for high-density particle systems (Coming soon/Experimental).

## 🎨 How to Use
1. Open `index.html` in any modern web browser.
2. Select a theme from the dropdown or use the **Prev/Next** buttons to cycle through options.
3. Adjust the count and speed sliders to your liking.
4. Pick your colors.
5. Toggle the music generator and use the **Prev/Next** audio buttons to find the perfect soundtrack.
6. Click **Hide Menu** to record your background.
